# IncidentLens MVP Spec

IncidentLens is an ADK incident-triage agent for analyzing supplied server and
application logs during a production incident.

## Scope

- Parse and analyze user-supplied logs.
- Identify relevant error signals without inventing evidence.
- Classify incident category as one of:
  - Application
  - Infrastructure
  - Database
  - Authentication / Authorization
  - Unknown / Insufficient Evidence
- Classify severity as one of:
  - LOW
  - MEDIUM
  - HIGH
  - CRITICAL
- Generate a structured report with classification, severity, summary, log
  evidence, confidence, next investigation steps, and uncertainty.

## Constraints

- Keep the first implementation simple.
- Use one ADK root agent and one deterministic helper tool.
- No deployment, observability, testing, evaluation datasets, Slack/email
  integration, automatic remediation, or multi-agent architecture in this step.
- If the logs do not contain enough evidence, explicitly state that evidence is
  insufficient instead of hallucinating a root cause.
